# Hope Hands Foundation Website

## Overview
This repository contains the **Part 1 and Part 2 Practical Outcomes Evaluation (POE)** project for WEDE5020.  
The project demonstrates the use of **HTML and external CSS** to build a responsive, styled website with navigation, branding, and deployment via GitHub Pages.

---

## Part 1
- Created a basic HTML structure (`index.html`).
- Linked an external stylesheet (`styles.css`).
- Added navigation links (Home, About, Programs, Donate, Contact).
- Uploaded the project to GitHub and set up the repository.

---

## Part 2
- Integrated a logo for branding.
- Styled the navigation bar with hover effects.
- Applied Flexbox for layout alignment.
- Ensured responsiveness with media queries (tested on mobile and different screen sizes).
